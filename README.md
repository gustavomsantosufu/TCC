# 📊 Análise Visual dos Gastos Públicos Municipais

Este repositório contém o trabalho de conclusão de curso de Gustavo M. Santos, cujo tema central é a análise visual dos gastos públicos municipais.

## ✨ Sobre o Projeto

A gestão e o acompanhamento dos gastos públicos são fundamentais para o desenvolvimento econômico e social de qualquer município. Compreender como o dinheiro público é aplicado não só promove maior transparência e participação cidadã, mas também auxilia gestores e órgãos de fiscalização a identificar padrões, tendências e possíveis falhas na administração dos recursos.

Este projeto busca transformar dados brutos sobre despesas públicas municipais em informações acessíveis, utilizando visualizações intuitivas e interativas. O objetivo é possibilitar que qualquer cidadão, independente de formação técnica, possa entender facilmente como os recursos estão sendo utilizados, promovendo assim uma gestão mais transparente e participativa.

## 🛠️ Funcionalidades

- Visualização clara e interativa dos principais indicadores de gastos públicos;
- Identificação de padrões e tendências de despesas ao longo do tempo;
- Ferramentas de apoio para tomada de decisão por parte de gestores e fiscalização;
- Acesso democrático à informação para toda a população.

## 🗂️ Fonte dos Dados

Os dados utilizados neste projeto foram extraídos do portal oficial do Governo do Estado de Minas Gerais:  
[https://dados.mg.gov.br/](https://dados.mg.gov.br/)

## 🚀 Motivação

Acreditamos que a transparência e o acesso à informação são pilares essenciais para uma sociedade mais justa e desenvolvida. Ferramentas visuais que transformam dados complexos em conhecimento acessível fortalecem o controle social e contribuem para melhores práticas de gestão pública.
